This run can't be reported as evidence

An evidence report is made only from the project's nominated evidence run, and an application run on it. Run "Dam raise v3, pan 0.8" fails two checks:

  • Its base run isn't the current nominated evidence run (it is based on "Baseline, 3 Jan", replaced on 12 Jan 2025).
  • It changes a baseline assumption: settings.panCoefficient (a project setting, not the proposal).

You can still open the ordinary catchment report for this run, or rebase the scenario on the nominated run.

A baseline-assumption change never disappears into a footnote. If an editor still wants it reported (to test a sensitivity, say), the report prints the red banner on every page and can't be issued.
